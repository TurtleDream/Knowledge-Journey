# ⚔ Академия Промпт-Инжиниринга (Diablo Edition)

Образовательный портал по промпт-инжинирингу на **Angular 17** (standalone-компоненты), оформленный в стилистике Diablo 2. Теория и практика неразрывно связаны: каждая статья содержит интерактивные упражнения, встроенные прямо в текст.

## 🚀 Быстрый старт

```bash
npm install
npm start        # или ng serve — запуск dev-сервера на http://localhost:4200
```

## 🏗️ Сборка и деплой на GitHub Pages

```bash
npm run build    # сборка в dist/prompt-engineering-academy
```

Для деплоя на GitHub Pages:

```bash
npm run deploy   # ng build --base-href=/Prompt-Engineering-Academy/ && npx angular-cli-ghpages --dir=dist/prompt-engineering-academy/browser
```

Замените `<repo-name>` на имя вашего репозитория. Убедитесь, что в настройках репозитория включён GitHub Pages (ветка `gh-pages`).

## 📚 Что внутри

### Статьи (5 штук, 1500–2500 слов каждая)
1. **Как работают LLM (интуитивно)** — токены, векторы, предсказание следующего слова
2. **Галлюцинации: распознавание и предотвращение** — причины и техники борьбы
3. **Структура эффективного промпта** — роль, контекст, задача, формат, ограничения
4. **Безопасность при работе с AI** — prompt injection, приватность, ответственное использование
5. **Токены и лимиты контекста** — окно контекста, суммаризация, retrieval

Каждая статья содержит 3–5 inline-упражнений, встроенных после соответствующих абзацев.

### Тест
- Страница `/test` — последовательность из **12 вопросов** разных типов
- Прогресс-бар, набранные баллы в реальном времени
- Сохранение прогресса в `localStorage` — можно продолжить после перезагрузки
- История результатов на странице `/results`

## 🧩 Архитектура компонентов

### Базовый класс `ExerciseBase`
Все упражнения наследуются от абстрактного класса `ExerciseBase` (`src/app/core/exercise-base.ts`):

- Управляет состояниями: `idle`, `correct`, `incorrect`, `partial`, `answered`
- Единый интерфейс: `@Input() data: ExerciseData`, `@Output() result: ExerciseResult`
- Режимы: `inline` (автономный, сразу показывает обратную связь) и `test` (передаёт результат родителю)

### Как добавить новый тип упражнения
1. Добавьте тип в `ExerciseType` в `src/app/core/exercise-types.ts`
2. Добавьте метаданные (иконку, цвет) в `EXERCISE_TYPE_META`
3. Создайте компонент, наследующий `ExerciseBase`
4. Зарегистрируйте его в `TYPE_COMPONENTS` в `src/app/exercises/exercise-host/exercise-host.component.ts`

### Динамический рендеринг
Компонент `ExerciseHostComponent` (`app-exercise-host`) динамически создаёт нужный компонент по `data.type`:

```html
<app-exercise-host [data]="exerciseData" [showLabel]="true"></app-exercise-host>
```

## 🎮 Реализованные типы упражнений

| Тип | Селектор | Описание |
|-----|----------|----------|
| **MultipleChoice** | `app-multiple-choice` | Одиночный/множественный выбор, частичная правильность |
| **MatchPairs** | `app-match-pairs` | Соединение пар кликами |
| **FillTheBlank** | `app-fill-the-blank` | Ввод пропущенного слова с синонимами |
| **TrueFalse** | `app-true-false` | Верно/неверно с объяснением |
| **OrderSteps** | `app-order-steps` | Расстановка шагов кликами |
| **CaseStudy** | `app-case-study` | Улучшение промпта: автопроверка + самооценка |
| **PromptSimulator** | `app-prompt-simulator` | Симуляция ответа AI, сравнение с эталоном |
| **SpotTheHallucination** | `app-spot-the-hallucination` | Выделение галлюцинации кликом по словам |
| **PromptBuilder** | `app-prompt-builder` | Сборка промпта из блоков |
| **PromptBattle** *(кастомный)* | `app-prompt-battle` | Выбор лучшего из двух промптов с объяснением |

## 💾 Сохранение прогресса

- **Прогресс теста** — `localStorage` ключ `peacademy-test-progress` (текущий индекс, баллы, отвеченные вопросы)
- **История результатов** — `localStorage` ключ `peacademy-test-history` (до 20 последних попыток)

## 🎨 Стилистика Diablo 2

- Тёмная готическая тема: чёрный/тёмно-серый фон, кроваво-красные и оранжевые акценты
- Шрифты: `Cinzel` (заголовки), `UnifrakturCook` (декоративные руны), `Open Sans` (текст)
- Кнопки-«каменные пластины», декоративные рамки, разделители-руны
- Полная адаптивность (mobile-first)
