# ⚔ Академия Промпт-Инжиниринга (Diablo Edition + Knowledge Journey)

Образовательный портал по промпт-инжинирингу на **Angular 17** (standalone-компоненты), оформленный в стилистике Diablo 2. Теория и практика неразрывно связаны: каждая статья содержит интерактивные упражнения, встроенные прямо в текст.

Дополнительно реализован модуль **«Путешествие по знаниям» (Knowledge Journey)** в стилистике Heroes of Might and Magic 3 — генерация персонализированных обучающих путешествий с помощью LLM.

## 🚀 Быстрый старт

```bash
npm install
npm start        # или ng serve — запуск dev-сервера на http://localhost:4200
```

## 🏗️ Сборка и деплой на GitHub Pages

```bash
npm run build    # сборка в dist/prompt-engineering-academy
```

Для деплоя на GitHub Pages:

```bash
npm run deploy   # ng build --base-href=/Prompt-Engineering-Academy/ && npx angular-cli-ghpages --dir=dist/prompt-engineering-academy/browser
```

Замените `<repo-name>` на имя вашего репозитория. Убедитесь, что в настройках репозитория включён GitHub Pages (ветка `gh-pages`).

## 📚 Что внутри

### Статьи (5 штук, 1500–2500 слов каждая)
1. **Как работают LLM (интуитивно)** — токены, векторы, предсказание следующего слова
2. **Галлюцинации: распознавание и предотвращение** — причины и техники борьбы
3. **Структура эффективного промпта** — роль, контекст, задача, формат, ограничения
4. **Безопасность при работе с AI** — prompt injection, приватность, ответственное использование
5. **Токены и лимиты контекста** — окно контекста, суммаризация, retrieval

Каждая статья содержит 3–5 inline-упражнений, встроенных после соответствующих абзацев.

### Тест
- Страница `/test` — последовательность из **12 вопросов** разных типов
- Прогресс-бар, набранные баллы в реальном времени
- Сохранение прогресса в `localStorage` — можно продолжить после перезагрузки
- История результатов на странице `/results`

### 🗺 Путешествие по знаниям (Knowledge Journey)
- Страница `/journey` — ввод темы/текста, выбор режима нарратива и сложности
- LLM генерирует 5–8 чекпоинтов с 2–4 активностями в каждом
- Типы активностей: MC, FB, FR, ELI5, TB, GYE, BC (BattleComponent)
- Таймер на каждый чекпоинт с автопереходом при истечении
- XP, streak, достижения, счётчики подсказок и пропусков
- Финальный отчёт с экспортом в PDF и JSON

## 🧩 Архитектура компонентов

### Базовый класс `ExerciseBase`
Все упражнения наследуются от абстрактного класса `ExerciseBase` (`src/app/core/exercise-base.ts`):

- Управляет состояниями: `idle`, `correct`, `incorrect`, `partial`, `answered`
- Единый интерфейс: `@Input() data: ExerciseData`, `@Output() result: ExerciseResult`
- Режимы: `inline` (автономный, сразу показывает обратную связь) и `test` (передаёт результат родителю)

### Как добавить новый тип упражнения
1. Добавьте тип в `ExerciseType` в `src/app/core/exercise-types.ts`
2. Добавьте метаданные (иконку, цвет) в `EXERCISE_TYPE_META`
3. Создайте компонент, наследующий `ExerciseBase`
4. Зарегистрируйте его в `TYPE_COMPONENTS` в `src/app/exercises/exercise-host/exercise-host.component.ts`

### Динамический рендеринг
Компонент `ExerciseHostComponent` (`app-exercise-host`) динамически создаёт нужный компонент по `data.type`:

```html
<app-exercise-host [data]="exerciseData" [showLabel]="true"></app-exercise-host>
```

## 🗺 Архитектура модуля Knowledge Journey

### Генерация
1. **Концепции** — LLM выделяет 5–10 атомарных концепций с зависимостями
2. **Чекпоинты** — концепции группируются в 5–8 чекпоинтов с нарративом
3. **Активности** — для каждого чекпоинта генерируются 2–4 активности

Промпты хранятся в `src/app/journey/prompts/journey.prompts.ts` — редактирование только через пересборку.

### Прохождение
- Пользователь проходит чекпоинты под таймером
- Таймер сохраняет timestamp начала — при перезагрузке продолжает идти
- При истечении — автозавершение активностей и переход дальше

### Оценка
- Свободные ответы (FR/ELI5/TB/GYE) оцениваются LLM по критериям: правильность 40%, полнота 30%, ясность 20%, пример 10%
- BattleComponent (BC) — диалог-полемика с ИИ, оценка понимания 0–100

### BattleComponent
- ИИ задаёт сложный вопрос → пользователь отвечает → ИИ находит слабое место и задаёт уточняющий вопрос
- Максимум 5 раундов
- В конце — оценка понимания 0–100 + развёрнутый фидбек

## 💾 Сохранение прогресса

- **Прогресс теста** — `localStorage` ключ `peacademy-test-progress` (текущий индекс, баллы, отвеченные вопросы)
- **История результатов** — `localStorage` ключ `peacademy-test-history` (до 20 последних попыток)
- **Journey** — `localStorage` ключи `kj-journey-state` и `kj-journey-data`
- **API-ключ LLM** — `localStorage` ключ `kj-llm-config`

## 🤖 LLM-интеграция

Поддерживаются бесплатные версии:
- **YandexGPT** (Yandex Cloud) — API-ключ
- **GigaChat** (Сбер) — API-ключ

Пользователь вводит API-ключ/токен в настройках (`/journey/settings`), хранится в localStorage. Никаких секретов в коде.

Универсальный промпт + пост-обработка для обеих моделей. Парсинг JSON устойчив к markdown и невалидному JSON (до 3 попыток).

## 🎨 Стилистика

### Diablo 2 (основной портал)
- Тёмная готическая тема: чёрный/тёмно-серый фон, кроваво-красные и оранжевые акценты
- Шрифты: `Cinzel` (заголовки), `UnifrakturCook` (декоративные руны), `Open Sans` (текст)
- Кнопки-«каменные пластины», декоративные рамки, разделители-руны
- Полная адаптивность (mobile-first)

### HoMM3 (Knowledge Journey)
- Пергаментные панели, золотые рамки
- Шрифты: `Cinzel` / `MedievalSharp`
- Интерактивная карта приключений с узлами-чекпоинтами и путями
- Hero panel (XP, streak, таймер, артефакты)
- BattleComponent — отдельный экран диалога

## 🧪 Как попробовать

1. Откройте главную страницу — увидите список статей
2. Зайдите в любую статью — в тексте будут интерактивные упражнения
3. Ответьте на вопросы — получите мгновенную обратную связь
4. Перейдите на `/test` — пройдите 12 вопросов разных типов
5. После завершения теста результат сохранится в истории на `/results`
6. Перезагрузите страницу во время теста — прогресс сохранится
7. Перейдите на `/journey` — введите тему и начните путешествие
8. Настройте API-ключ в `/journey/settings`
9. Пройдите чекпоинты, сразитесь в битве, получите отчёт
