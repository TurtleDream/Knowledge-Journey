# ⚔ Академия Промпт-Инжиниринга (Diablo Edition + Knowledge Journey)

Образовательный портал по промпт-инжинирингу на **Angular 17** (standalone-компоненты, signals, zone.js), оформленный в стилистике Diablo 2. Теория и практика неразрывно связаны: каждая статья содержит интерактивные упражнения, встроенные прямо в текст.

Дополнительно реализован модуль **«Путешествие по знаниям» (Knowledge Journey)** в стилистике Heroes of Might and Magic 3 — генерация персонализированных обучающих путешествий с помощью LLM. Пользователь вводит тему или текст (до 20 000 символов), система извлекает изученные чанки через RAG, и LLM генерирует концепции → чекпоинты → активности. Если изученных материалов мало — система подсказывает, что почитать сначала.

## 🚀 Быстрый старт

```bash
npm install
npm start        # или ng serve — запуск dev-сервера на http://localhost:4200
```

Для работы генерации Journey и RAG нужен локальный бэкенд:
```bash
node server/index.js
```
или одним процессом (бэкенд с автоперезапуском):
```bash
npm run start:all
```

## 📚 Что внутри

### Статьи (5 штук, 1500–2500 слов каждая, `src/app/content/articles.data.ts`)

1. **Как работают LLM (интуитивно)** — токены, векторы, предсказание следующего слова
2. **Галлюцинации: распознавание и предотвращение** — причины и техники борьбы
3. **Структура эффективного промпта** — роль, контекст, задача, формат, ограничения
4. **Безопасность при работе с AI** — prompt injection, приватность, ответственное использование
5. **Токены и лимиты контекста** — окно контекста, суммаризация, retrieval

Каждая статья содержит 3–5 inline-упражнений, встроенных после соответствующих абзацев. У каждой статьи — кнопка **«Я изучил эту статью»**: она помечает статью изученной, обновляет SQLite-индекс и отправляет событие в UserContextService (для формулы mastery). Без этого отметки тренировка в чате и Journey «пустеют» — вопросы идут только по изученным чанкам.

### Тест (`/test`, 12 вопросов из `src/app/content/test-questions.data.ts`)

- Страница `/test` — последовательность из **12 вопросов** разных типов
- Прогресс-бар, набранные баллы в реальном времени
- Авто-переход к следующему вопросу после ответа
- Сохранение прогресса в `localStorage` — можно продолжить после перезагрузки
- История результатов на странице `/results` (до 20 последних попыток)

Типы вопросов в тесте: `multiple-choice`, `true-false`, `fill-the-blank`, `match-pairs`, `order-steps`, `prompt-battle`, `spot-the-hallucination`, `prompt-builder`, `case-study`.

### Оракул (AI-помощник, `src/app/ai/`)

- Кнопка 🔮 справа внизу (FAB-компонент `ai-chat-button`) — чат с AI. Бейдж на кнопке показывает количество слабых тем (score < 0.5), которые стоит проработать.
- Панель чата «Оракул» (`ai-chat-panel`):
  - **RAG-ответы**: при ответе на вопрос система ищет релевантные чанки через cosine similarity (top-5), формирует контекст и запрашивает LLM. Ответ маркируется «✓ На основе платформы» / «Общие знания» (если модель использовала свои знания). Цитаты `[N]` ведут на статьи.
  - **Тогл «Поиск по изученному»**: фильтрует RAG только по чанкам, помеченным `studied=1`. Без этого тренировка и вопросы идут по всему индексу.
  - **Чипы быстрого вызова**:
    - «📊 Анализ прогресса» — слабые темы + рекомендации с артиклами (в чат, без модалки)
    - «🎯 Рекомендации» — что изучить дальше, смежные навыки, формулировка для резюме
    - «⚔ Тренировка по изученному» — лёгкое путешествие «вопрос-ответ» прямо в чате
- **Тренировка в чате** (`ChatJourneyService`): вопросы только по **изученным** материалам. Пользователь отвечает → LLM оценивает (верно/есть пробелы) → событие попадает в UserContextService → обновляется mastery. Сразу следующий вопрос. Без изученных чанков тренировка не стартует — предлагается сначала открыть статью и отметить её.
- **Модалки**:
  - `recommendations-modal` — подробные рекомендации: nextTopics (с retrieval-артиклами), relatedSkills, resumeSuggestion.
  - `progress-analyzer` (в `journey/components/progress-analyzer`) — модалка анализа прогресса: слабые темы, рекомендации, summary.
- **Таблица `/ai`** — отдельная страница (`AiComponent`) с табами: Чат, Анализ прогресса, Рекомендации, Генератор Journey.
- Важно: статьи помечаются «Я изучил эту статью» → чанки становятся для RAG-поиска. Без этого тренировка пустеет.
- `apiBase()`: отлично работает и с прокси `ng serve`, и вне localhost (CORS открыт на бэкенде). На другой машине внутри сети можно положить origin бэкенда в `localStorage.kj-api-base`.

### Генерация Journey по изученным темам (`src/app/journey/`)

- Кнопка «🎯 Тема по моему прогрессу» (`JourneyGeneratorService.suggestTopicFromProgress`) предлагает тему из 3 самых слабых тем прогресса (где score ниже всего).
- Journey генерируется на основе **изученных материалов платформы**: перед концепциями/чекпоинтами LLM получает блок из изученных чанков (RAG, `onlyStudied: true`, фильтр в SQL до top-k, источники под каждым чекпоинтом).
- Порог: если изученных чанков < 3 (`MIN_STUDIED_SOURCES = 3`) — генерировать нельзя, система предлагает сначала изучить статьи (список ссылок).
- У каждой статьи — кнопка «Я изучил эту статью» (помечает статью изученной через `ReindexService.markStudied` + событие в `UserContextService`).
- При «Обновить индекс» изученность сохраняется (иначе бы стиралась при пересоздании статьи) — `reindexArticle` сохраняет `wasStudied` и переносит `studied=1` на новые чанки.
- Страница `/journey` (`JourneyInputComponent`) — ввод темы/текста (до 20 000 символов), выбор режима нарратива и сложности, кнопка «Тема по моему прогрессу», «Настройки API».
- Режимы нарратива: Классика, Startup, Инцидент, Консалтинг, Аудит.
- Сложность: Лёгкая / Средняя / Сложная.
- LLM генерирует 5–10 концепций → 5–8 чекпоинтов → 2–4 активности на чекпоинт.
- Типы активностей: **MC** (MultipleChoice), **FB** (FillBlank), **FR** (FreeResponse), **ELI5** (ExplainLikeImFive), **TB** (TeachBack), **GYE** (GiveYourExample), **BC** (BattleComponent).
- Таймер на каждый чекпоинт (`TimerComponent`) с автопереходом при истечении (цвет: зелёный → жёлтый → красный, пульсация <30 сек).
- XP, streak, достижения (first-step, streak-5, blade-master, archivist, unstoppable), счётчики подсказок (3) и пропусков (1, +1 за hard-сложность).
- Финальный отчёт (`JourneyReportComponent`) — «Свиток знаний»: общий результат, карта чекпоинтов, таблица активностей, слабые места, рекомендации. Экспорт в **PDF** (jspdf) и **JSON**.

### Упражнения (`src/app/exercises/`, 10 типов)

Все типы используют общий базовый класс `ExerciseBase` (состояния: idle → correct/incorrect/partial/answered) и хост `ExerciseHostComponent` (динамическая загрузка по `data.type`). Обратную связь рисует `ExerciseFeedbackComponent`.

1. **multiple-choice** — выбор одного или нескольких вариантов, частичный балл за частичный ответ.
2. **match-pairs** — соедини пары: клик по левому элементу, затем по правому; можно разъединять. Проверка когда соединены все.
3. **fill-the-blank** — заполни пропуск (`___`) в тексте. Поддерживает синонимы и case-sensitive режим.
4. **true-false** — верно / неверно.
5. **order-steps** — расставь шаги в правильном порядке. Начальный порядок перемешан, 배치 через клик «шаг → позиция».
6. **case-study** — улучши промпт: пишешь свой вариант, автооценка по ключевым элементам (частичным совпадением keywords), потом самооценка 1–5. Итог = среднее.
7. **prompt-simulator** — напиши промпт, который привёл бы к заданному ответу AI. Автооценка по ключевым словам + самооценка.
8. **spot-the-hallucination** — клик по словам, которые, по мнению пользователя, являются галлюцинацией. Оценка по диапазону: полное попадание / частичное пересечение.
9. **prompt-builder** — собери промпт из блоков в правильном порядке (drag-to-order через клики).
10. **prompt-battle** — выбери лучший из двух промптов и объясни почему (автооценка по battleWinnerId).

Для теста и Journey используются те же компоненты упражнений — через `ExerciseHostComponent` с `mode: 'test'` или inline.

## 🧩 Архитектура компонентов

### Базовый класс `ExerciseBase`
Все упражнения наследуются от абстрактного класса `ExerciseBase` (`src/app/core/exercise-base.ts`):

- Управляет состояниями: `idle`, `correct`, `incorrect`, `partial`, `answered`
- Единый интерфейс: `@Input() data: ExerciseData`, `@Output() result: ExerciseResult`
- Режимы: `inline` (автономный, сразу показывает обратную связь) и `test` (передаёт результат родителю)

### Как добавить новый тип упражнения
1. Добавьте тип в `ExerciseType` в `src/app/core/exercise-types.ts`
2. Добавьте метаданные (иконку, цвет) в `EXERCISE_TYPE_META`
3. Создайте компонент, наследующий `ExerciseBase`
4. Зарегистрируйте его в `TYPE_COMPONENTS` в `src/app/exercises/exercise-host/exercise-host.component.ts`

### Динамический рендеринг
Компонент `ExerciseHostComponent` (`app-exercise-host`) динамически создаёт нужный компонент по `data.type`:

```html
<app-exercise-host [data]="exerciseData" [showLabel]="true"></app-exercise-host>
```

## 🗺 Архитектура модуля Knowledge Journey

### Генерация
1. **Концепции** — LLM выделяет 5–10 атомарных концепций с зависимостями
2. **Чекпоинты** — концепции группируются в 5–8 чекпоинтов с нарративом
3. **Активности** — для каждого чекпоинта генерируются 2–4 активности

Промпты хранятся в `src/app/journey/prompts/journey.prompts.ts` — редактирование только через пересборку.

### Прохождение
- Пользователь проходит чекпоинты под таймером
- Таймер сохраняет timestamp начала — при перезагрузке продолжает идти
- При истечении — автозавершение активностей и переход дальше

### Оценка
- Свободные ответы (FR/ELI5/TB/GYE) оцениваются LLM по критериям: правильность 40%, полнота 30%, ясность 20%, пример 10%
- BattleComponent (BC) — диалог-полемика с ИИ, оценка понимания 0–100

### BattleComponent
- ИИ задаёт сложный вопрос → пользователь отвечает → ИИ находит слабое место и задаёт уточняющий вопрос
- Максимум 5 раундов
- В конце — оценка понимания 0–100 + развёрнутый фидбек

## 💾 Сохранение прогресса

- **Прогресс теста** — `localStorage` ключ `peacademy-test-progress` (текущий индекс, баллы, отвеченные вопросы)
- **История результатов** — `localStorage` ключ `peacademy-test-history` (до 20 последних попыток)
- **Journey** — `localStorage` ключи `kj-journey-state` и `kj-journey-data`
- **API-ключ LLM** — `localStorage` ключ `kj-llm-config`

## 🤖 LLM-интеграция

Поддерживаются бесплатные версии:
- **YandexGPT** (Yandex Cloud) — API-ключ
- **GigaChat** (Сбер) — API-ключ
- **ChatGPT** (OpenAI) — API-ключ (модель `gpt-4o-mini` по умолчанию)
- **DeepSeek** — API-ключ (модель `deepseek-chat` по умолчанию)

Пользователь вводит API-ключ/токен в настройках (`/journey/settings`), хранится в localStorage. Никаких секретов в коде.

Универсальный промпт + пост-обработка для обеих моделей. Парсинг JSON устойчив к markdown и невалидному JSON (до 3 попыток).

## 🎨 Стилистика

### Diablo 2 (основной портал)
- Тёмная готическая тема: чёрный/тёмно-серый фон, кроваво-красные и оранжевые акценты
- Шрифты: `Cinzel` (заголовки), `UnifrakturCook` (декоративные руны), `Open Sans` (текст)
- Кнопки-«каменные пластины», декоративные рамки, разделители-руны
- Полная адаптивность (mobile-first)

### HoMM3 (Knowledge Journey)
- Пергаментные панели, золотые рамки
- Шрифты: `Cinzel` / `MedievalSharp`
- Интерактивная карта приключений с узлами-чекпоинтами и путями
- Hero panel (XP, streak, таймер, артефакты)
- BattleComponent — отдельный экран диалога

## 🧪 Как попробовать

1. Откройте главную страницу — увидите список статей
2. Зайдите в любую статью — в тексте будут интерактивные упражнения
3. Ответьте на вопросы — получите мгновенную обратную связь
4. Перейдите на `/test` — пройдите 12 вопросов разных типов
5. После завершения теста результат сохранится в истории на `/results`
6. Перезагрузите страницу во время теста — прогресс сохранится
7. Перейдите на `/journey` — введите тему и начните путешествие
8. Настройте API-ключ в `/journey/settings`
9. Пройдите чекпоинты, сразитесь в битве, получите отчёт
